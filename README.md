# Credit Risk Intelligence System

Machine Learning based credit default prediction system using Random Forest and Streamlit.

## Features
- Credit default prediction
- Risk score analysis
- Professional dashboard
- Interactive UI
- Real-time predictions

## Technologies
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## Model Used
- Random Forest Classifier
